# Product Specification — MediaMinds VCR

## Core objective

Create a centralized intelligence dashboard that:

- analyzes competitors,
- tracks social velocity,
- identifies content gaps, and
- generates strategic recommendations.

## Key capabilities

- Competitive discovery
- Tier classification
- Social velocity tracking
- Keyword intelligence
- AI visibility monitoring
- Content opportunity detection
- Strategy generation

## Tier system

- **A**: national influencers or dominant authorities
- **B**: strong industry leaders
- **C**: regional competitors
- **D**: local direct competitors

### Scoring weights

- geographic relevance: `0.25`
- service relevance: `0.25`
- search visibility: `0.15`
- local pack presence: `0.10`
- social velocity: `0.10`
- engagement ratio: `0.05`
- authority signals: `0.05`
- platform diversity: `0.05`

## Social velocity metrics

### Tracked

- `posts_last_7_days`
- `posts_last_30_days`
- `average_views`
- `average_likes`
- `average_comments`
- `follower_growth`
- `engagement_ratio`

### Derived

- `velocity_score`
- `consistency_score`
- `short_form_video_ratio`

## Delivery phases

### Phase 1

- client onboarding
- manual competitor entry
- basic radar chart
- database integration

### Phase 2

- automated competitor crawler
- social velocity metrics
- keyword tracking
- dashboard analytics

### Phase 3

- AI visibility detection
- content opportunity engine
- strategy generation
- automated reporting
